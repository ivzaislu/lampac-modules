# FanCDN.2.0

Внешний онлайн-модуль для **Lampac / Lampac NextGen**, работающий с FanSeries и потоками FanCDN.

Домен по умолчанию: `https://1fanserials.org`. Потоки отдаются через `HostStreamProxy` (`streamproxy: true`). Модуль по умолчанию выключен (`enable = false`) и включается в `init.conf`.

## Требования

Для работы нужны:

- непустая авторизованная `cookie` FanSeries;
- включённый Playwright — он используется как резервный транспорт, если обычный HTTP-запрос не прошёл или вернул anti-bot/auth-страницу.

Источник добавляется для фильмов и сериалов при `kinopoisk_id > 0`.

## Установка

Добавьте модуль в `module/repository.yaml`:

```yaml
- repository: https://github.com/ivzaislu/lampac-modules
  branch: main
  modules:
    - FanCDN.2.0
```

После сохранения перезапустите Lampac.

## Поиск и HTTP

Поиск выполняется через:

```text
/engine/ajax/msearch.php?q=...
```

Поиск, страницы контента и API сначала запрашиваются обычным HTTP с cookie. Если ответ пустой, похож на anti-bot challenge или требует авторизацию, используется Playwright fallback.

Одновременно допускается не более двух Playwright-загрузок внутри Controller и не более двух внутри Service.

Поиск учитывает `title`, `original_title` и `alt_titles`.

Для сериалов алгоритм дополнительно:

- сначала предпочитает точные совпадения названий;
- затем допускает частичное совпадение для названий длиной от 4 символов;
- год используется как приоритет сортировки кандидатов, а не как жёсткий фильтр;
- частичные совпадения принимаются только после проверки Kinopoisk ID на странице;
- кандидаты перебираются по очереди, поэтому неверный первый результат `msearch` не блокирует остальные.

Общая проверка anti-bot/auth-ответов и нормализация URL вынесены в `Helpers.cs`.

## Фильмы

Flow:

1. `msearch.php` находит страницу фильма.
2. Из страницы извлекается iframe `/movies/{kp}?key=...`.
3. `kp` сверяется с запрошенным `kinopoisk_id`.
4. `/film.php?kp={kp}&key=...` возвращает JSON с вариантами воспроизведения.
5. Разрешаются только прямые `cdn.fancdn.net` / `*.cdn.fancdn.net`.
6. HLS и субтитры отдаются через `HostStreamProxy`.

Если обычный HTTP получил страницу фильма, но player iframe в ней отсутствует, та же страница перечитывается через Playwright fallback.

## Сериалы

Flow:

1. `msearch.php` возвращает кандидатов.
2. Кандидаты ранжируются по качеству совпадения названия и близости года.
3. Для URL вида `/index.php?newsid=...` загружается страница и извлекается canonical URL.
4. Kinopoisk-маркер, если он есть, сверяется с запрошенным `kinopoisk_id`; для частичных совпадений маркер обязателен.
5. Из страницы по возможности сразу извлекается список сезонов.
6. Страница выбранного сезона даёт ссылки на эпизоды.
7. Страницы эпизодов загружаются HTTP-first с ограниченным параллелизмом.
8. Из `window.cdnData[...]` извлекаются озвучка и прямой FanCDN HLS.
9. Список эпизодов сортируется и дедуплицируется по номеру.
10. По озвучкам строится `VoiceTpl`, по сериям — `EpisodeTpl`.

Локальный player URL вида:

```text
/player/?file=https://cdn.fancdn.net/tvseries/.../hls.m3u8&...
```

разбирается напрямую, без отдельной загрузки `/player/`.

Внешние видеохосты, например `ylitron.pro`, не используются: serial-flow принимает только прямые FanCDN HLS.

## Конфигурация

Минимальный пример `init.conf`:

```json
"FanCDN.2.0": {
  "enable": true,
  "cookie": "dle_user_id=<value>; dle_password=<value>"
}
```

Не публикуйте значения cookie.

Параметры по умолчанию:

- `displayindex = 520`
- `imitationHuman = true`
- `streamproxy = true`
- `host = https://1fanserials.org`

## Маршрут

```text
GET /lite/fancdn.2.0
```

Основные параметры сериалов:

- `serial=1` — режим сериала;
- `s` — номер сезона;
- `voice` — выбранная озвучка.

`OnlineApiQuality` для `fancdn.2.0`: ` ~ 1080p`.

## Именование

Пользовательское имя, каталог, проект и секция конфигурации: `FanCDN.2.0`.

В C# точки нельзя использовать в namespace и идентификаторах, поэтому внутреннее пространство имён — `FanCDN2_0`.
